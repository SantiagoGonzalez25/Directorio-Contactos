# Directorio de Contactos

**Nombre completo:** Santiago Restrepo González
**Sistema Operativo:** Windows 11 

## Tecnologias utilizadas
* React Native
* Expo
* Firebase (Cloud Firestore)
* React Navigation

## Antes de comenzar
asegúrate de tener instalado lo siguiente en tu entorno local:
* Node.js
* La aplicación **Expo Go** en tu celular o un emulador

## Pasos para ejecutar el proyecto

1. Clonar el repositorio usando: `git clone [URL_DE_TU_REPOSITORIO]`
2. Entrar a la carpeta del proyecto en la terminal.
3. Instalar las dependencias ejecutando: `npm install`
4. Crear un archivo `.env` en la raíz del proyecto copiando la estructura de `.env.example` y agregando las credenciales de Firebase.
5. Iniciar la aplicación ejecutando: `npx expo start`
